# Retail Sales Data Analysis

## Project Overview

This project analyzes retail sales data to uncover valuable business insights, identify sales trends, evaluate profitability, and support data-driven decision-making. The analysis was performed using Python and data science libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## Objective

The main objectives of this project are:

* Perform data cleaning and preprocessing.
* Analyze sales and profit performance across categories and regions.
* Identify top-performing products and customers.
* Visualize trends and patterns in sales data.
* Generate actionable business insights.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
